# CODSOFT - Task 1: Smart ChatBot 🤖

This is a simple AI chatbot built using Python.

### 🔧 Features:
- Answers factual questions using Wikipedia
- Tells the current time
- Tells random jokes
- Gracefully handles unknown questions

### ▶️ How to Run:
1. Install dependencies:
pip install wikipedia

2. Run the chatbot:
python smart_chatbot.py
